# Dongryo Dev 플러그인을 설치했습니다

1. 설치 중에 봇 토큰(`DONGRYO_DEV_TOKEN`, `dr_bot_…`)을 넣지 않았다면 Hermes 설정의 메시징(Gateway) 화면에서 **Dongryo Dev** 를 열고 넣습니다.
   주소(`DONGRYO_DEV_URL`)는 관리자에게 받은 개발 환경 주소입니다.
2. Hermes 게이트웨이를 다시 시작합니다.
3. Dongryo 의 에이전트 화면에서 이 에이전트에게 말을 걸어 봅니다.

업데이트: `hermes plugins update dongryo-dev` · 안내: 개발 환경 주소의 /guide/hermes-bot
